# database-migrations

## Apa ini
Best practice migrasi database — perubahan schema, migrasi data, rollback, dan deployment tanpa downtime — untuk PostgreSQL, MySQL, dan ORM umum (Prisma, Drizzle, Kysely, Django, TypeORM, golang-migrate).

## Kapan dipakai
Saat membuat atau mereview migrasi database, terutama yang berisiko terhadap downtime atau butuh rencana rollback.
