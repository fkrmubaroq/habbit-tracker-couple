# e2e-testing

## Apa ini
Pola E2E testing berbasis Playwright — Page Object Model, contoh config, manajemen artifact, dan strategi mengatasi test yang flaky. Ini murni referensi, tidak bisa dieksekusi langsung.

## Kapan dipakai
Sebagai referensi pola saat menulis test E2E. Untuk benar-benar menjalankan suite E2E sebuah webapp dan menghasilkan report standar, pakai `webapp-testing`.
