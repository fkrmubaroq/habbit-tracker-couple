# deployment

## Apa ini
Praktik rilis yang aman saat mengirim perubahan ke environment nyata — checklist pra-deploy, rencana rollback, rollout bertahap (feature flag/canary), dan verifikasi pasca-deploy.

## Kapan dipakai
Saat user minta deploy, release, ship ke production/staging, atau merencanakan bagaimana sebuah perubahan berisiko sebaiknya dirilis.

## Bukan untuk
- Manajemen branch git lokal (lihat `branching`).
- Konfigurasi pipeline CI itu sendiri — skill ini soal keputusan/judgment di seputar rilis, bukan mekanika satu platform tertentu.
